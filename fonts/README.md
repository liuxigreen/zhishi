# Shared fonts

All style demos symlink `demo/fonts` → this directory.

- Chinese VF: `NotoSansSC-VF.ttf`, `NotoSerifSC-VF.otf`
- UI: `InterTight-Variable.ttf`, `GeistMono-VF.ttf`
- Display: `MaShanZheng*.ttf`, `ZCOOLXiaoWei.ttf`
- Lemo small faces also live here (Inter, subsets, etc.)

`fonts.css` covers the Vibe own-pack families. Some Lemo demos ship their own `@font-face` in HTML pointing at filenames in this folder — keep names stable.
