# 24s 自有示范 → ≥20 世界全片（桥）

一句话：**长相与人物/道具语法从 own 包来；故事床与换场按我们的 STRUCTURE，不扩写成「把 demo 拉长」。**

## 从示范里带走什么
- **Look：** palette / 光 / 材质 / 字幕纪律（STYLE.md + `demo/look.js`）
- **People：** 人物比例与情绪语言（§12 + `people.js`）— 全片复用，禁止换成竹竿/色块除非该包本就是那种语言
- **Props grammar：** §13 + `props.js` / `motion.js` — 用生成语法**衍生新道具与新展示**，不是只循环 demo 那几件
- **节奏感：** demo 的转场手法（墨晕、纸草卷、lightsDip…）可作「换场动词」，但场次内容来自 CONTENT 板

## 丢掉什么
- demo 的 24s 剧情线、道具时间表、DEMO.md 分镜
- 把 4–6 个 demo 世界硬复制成 20 个「换皮同构图」
- Lemo / own demo 里的旁白或口播床当全片人声（成片 = **字幕 only**；可有无旁白配乐）

## 扩成 120–150s / ≥20 世界的做法
1. CONTENT-BOARDS Pass（短板≥6 · densest≥5 · 道具链≥3 · 每板态差+接触点）。
2. 写 STRUCTURE：五段弧 · **剧情推动换场** · ≥20 不同可读世界 · 一镜旅行相机 · 静音 2s 能懂因果。
3. 每个世界：沿用锁风的 people 语言；道具按 §13 **新造或变形态**（连续变化，不是一幕一固定道具）。
4. 字幕：白话因果句 · ≥4.5:1 · 无旁白承担讲解。
5. 探针帧先过，再 densest；渲染者只标 **READY**。

## 和 Lemo 出片的关系
Lemo 适合题材时可锁：`STYLE.md` 的色/材/光/字/人/道具/运动语法/原生动作 **全跟、不稀释**。  
同样走本桥的 STRUCTURE（≥20 · 剧情换场 · 字幕）；**禁旁白**；**不得**把 Lemo demo 当本集剧本，也不得把结果标成「自蒸」。
