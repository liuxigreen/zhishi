## 1 · 四问 + 角度 + 故事床
选题过四问才写板：**钩**（可截图）· **故事线**（谁较劲）· **可模拟**（能演）· **反转**（同物新义）。  
同一构念 ≥**3** 独立角度（误读/对方视角/机制/对照演法/边界/照进你…），由**同一故事床**串——故事是载体，角度是论证刀数。  
**BAN：** 单故事线冒充全片；单钩薄片。

## 2 · 密度门槛 + Ember 职能（不是槽位）
| 门槛 | 数 |
|---|---|
| densest 论证板 | ≥5 |
| short | ≥8（方法/机制）或 ≥6（短钩） |
| 每板时长 | 6–14s；禁单句缓放 |
| 道具链 | ≥3；至少一物跨 ≥3 板变态 |
| 每板必填 | 屏上句 + 态差 + 接触点；无接触=纸上板→Hold |
| 原典 | ≥1 板可指认（作者·书/刊·年或典籍卷次）；禁空「研究表明」 |
| 结构 | 三候选；**至少一个拒绝抄 Ember 九槽** |

**Ember 职能表**（覆盖检查，不是必填顺序）：钩·误读·机制·原典·方法·反转·回钩。习惯重训才需要一天轴/五日反抗；多数题不需要。  
屏上简化说明写「简化模型」/「据××」——**「示意」是观感否决词，不上屏**（裁决 C1）。

## 3 · 卡·史（旧 A · 历史/人物戏）
**KEEP：** 打脸钩=身份×反直觉；时间/规程箱承载论证非流水账；先演后命名；SourceFooter 据××同帧；缺席当戏；回钩同物新义。  
**BAN：** 涨幅 HUD/年号墙；twin 抄钩原句；无典籍脚注的史空话；R 切字卡当旅程句。

## 4 · 卡·心（旧 B · 心理/机制/情绪短）
**KEEP：** 日常悖论→误读→机制→原典→回钩；构念分账先表后板；脚注同帧；情绪短片 2–6 板即可。  
**BAN：** 单钩薄片；强制 Ember 三步+一天；星座词云冒充原典；危害列表墙。

## 5 · 卡·法（旧 C · 方法/科学/体感课）
**KEEP：** 先例子/体感后命名；检查单/计数有态变；方法步可演接触；加载轴仅习惯重训且标非定律。  
**BAN：** 鸡汤无计数；默认 Ember 九槽；开场考试体无先演；人物命运史诗句（那是史）。
