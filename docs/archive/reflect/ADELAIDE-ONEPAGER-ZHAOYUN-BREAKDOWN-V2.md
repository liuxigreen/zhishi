# 给 Adelaide · 为什么苏轼 v6/v7 仍不像来龙（实测 Top KEEP）

对照片：你贴的来龙赵云 ~4min（`breakdown-v2/`，复用 83 张@3s + 9 hard cuts，**不是剧情复述**）。

## Top KEEP（按杀伤力）

1. **床选错会全盘飞**  
   赵云主床 = **H-stage 宫廷纸偶戏**（灯、柱、匣、卷）+ **H-doc 课本**；地图只在「魏军真来了」点缀。  
   **v6** = 俯视地图棋盘 + 涨幅% → 直接错册。  
   **v7** = 改成草屋侧舞台，方向对了，但还在用「空舞台」。

2. **Prop-acting A，不是站桩**  
   赵云：压匣 / 展卷 / 摇铃 / 抱红婴 / 空金画框 / 托盘挨训 / 出城门。纸偶**手在干活**。  
   **v7** 锄没握住、圆脸微笑站桩 → 观感仍假。

3. **DualMark 是语法，不是装饰**  
   左上 cream 句 + **蓝**事实下划 + **红**冲突下划（压下 / 训 / 真来了）+ 底右「据××/示意」。  
   少了这一套，再像的纸偶也不来龙。

4. **机位几乎永远 Static**  
   测得 motionμ≈3.09；9 次硬切≈2.17/min；板内靠 soft 态变密起来。  
   **禁止**用假推拉充密度；密度=道具态 + 字态。

5. **先演后命名 + 回钩**  
   「亲贤臣，远小人」演到结尾才作答；开头军报 ↔ 结尾「军报被压下了，表却留下」。  
   行程单式「从早到晚四件事」永过不了钩门。

6. **缺席也是戏**  
   空画框、删线「不会来」、该来的魏军。翻盘要看得见空，不是换形容词。

7. **体量/光**  
   满宽地面 + 灯火点光源 + grain≈17 + 柱框；不是细线 HUD，也不是空褐板贴一个小人。

## 一句话
来龙这条不是「知识地图动画」，是 **静音舞台史剧**：纸偶演戏 → 字 DualMark 点穴 → 脚注托底。v6 车道错；v7 车道对但戏与字未满血。
