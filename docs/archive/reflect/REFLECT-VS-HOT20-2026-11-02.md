## 五条真话（相对 KEEP 我们自己写过却没做到）
1. **观赏度门没真跑**：checklist Pass ≠ 会停滑。火片钩能截图当封面；我们钩是说明句配示意图。
2. **把「新颖选题」当救命**：换 Agent 空转躲开宜家/沉没，但用的还是**说明书镜头语法**（计数+按钮+脚注）。火片再偏知识也先是**戏/景**。
3. **persist 床有名无体**：BigRedButtonBed 只有「钮」，没有房间、机箱、人、后果舞台；对比烽火床=整片国境地形。
4. **主讲权被字抢走**：火片字钉在动作上；我们字开场就铺满，动作是点缀。
5. **蒸馏→出片断了**：ESSENCE/CARDS/MEASURED 越写越全，densest 仍用同一套 canvas 示意壳——**工艺栈在自我安慰**。

## 对流量 / 获奖
- 流量：封面不抢、前 1s 无冲突画面、中段重复计数 → 划走概率高。  
- 获奖/大赏感：无材质、无戏、无「看完记得一个画面」→ 与账号「知识大赏」名不符。

## 下一刀硬规（写进 evolve，不辩解）
1. densest 交审前强制：**静音裁底 10s** —— 只靠画面能讲清机制；否则 Fail。  
2. 钩帧必须单独能当封面（人物或大物态，禁纯标题+小图标）。  
3. 床占画幅中区须有**体量**（对比火片：地形/舞台/雕塑字）；中区只剩小 UI = Fail。  
4. 禁止「换题救命」：题新但镜头仍是示意壳 → 同 Fail。  
5. 再开渲前先贴 **1 张火片钩帧 + 1 张本片钩帧** 并排自骂，再决定是否交 Adelaide。
