## D. 为什么「越做越垃圾」

**技术：**

1. **默认 CODE 车道**没有从火片锁死的「静帧语法包」（光位、材质、中区填充、禁灰虚空、禁细线 HUD 当主戏）。每集从 `fillRect` 暗底 + 几何人重新发明一次「能看懂」的示意。  
2. 补丁只改 **内容角 / bbox 大小 / 删一个禁壳字段**，不换 **渲染母语** → 版本号涨、观感同源。  
3. contact / mute / 角度表越做越完整 → **工艺自我安慰**（与 `REFLECT-VS-HOT20` 第 5 条同一病）。

**创作 / 审片：**

4. Jules Pass **过软**：允许 residual「色块巨头 / 俯视示意 / 锁相圆环偏图解」仍 Pass；Adelaide 级门（并排火片会不会划走）没一票否决。  
5. 把「听 Adelaide」理解成 **立刻重渲**，而不是 **先填反思表再决定是否准渲** → 越听话壳越厚，观感越像流水线废片。

**一句话：**  
蒸馏数据在增加 **描述能力**；出片栈在重复 **同一种廉价可见性**。描述↑、观感↓，体感就是「越做越垃圾」。
