## 0 · 一句话

从选题库 **一次只开一题**（或 densest 试味批 ≤3）：  
**锁题 → UPGRADE → 蒸馏/底座 → densest 10s → Gate+HUMAN-CHECK → 你看 densest → short 45s–3min → PC 三件套 → 上梯子。**  
质量不够（Gate 红 / 你说不好看 / vanity）→ **停，不灌全片。**

## 1 · 出片流水线（逐步）

### Step 0 · 从库里拣题（不重开已做）
1. 打开 `TOPIC-BANK-100-2026-11-01.md` **主表待拍**（附录历史勿回填）。
2. 对照 `PROGRESS-LADDER.md` 最近 3 集理论族 + craft 家族。
3. 勾选条件（全过才开拍）：
   - 与近集 **理论族不撞车**（学习科学 / 决策偏差 / Salimpoor DROP / 已发聚光灯·测试效应）
   - **craft 家族 ≠ 上一集**（轮换）
   - 库内备注「隔开拍 / 稀疏」已满足
   - 非 **ban list**（见 §3.3）
4. 写开拍声明一行进梯子草稿：`#N 标题 · 理论族 · craft · 升级轴`

### Step 1 · UPGRADE.md（缺则停）
路径：`episodes/<slug>/UPGRADE.md`  
必填：
- 相对上一 shipped：**至少 1 条可验升级轴**（理论族 / 工艺语法 / 道具 N / 图内展示 / 硬失败清零）
- `narrative_mode`：`story_scene` | `diagram_bed` | `hybrid`
- 目标全长：**由拍推算**（silent 故事常 ~45s–3min）；**禁**写死 5/6/8/15 分钟凑数
- 本集 BANNED twin 对照（底座列表 + 近集皮）

### Step 2 · 蒸馏 / 底座锁定
1. 优先 **复用已有 STYLE-BASE**（见 §3 映射表）；仅当库建议 craft 无底座或底座挂起时才新蒸。
2. 九项齐（`DISTILL-MULTIDIM.md`）：Argument · 字阶≥4 · 色板职责 · 3s 动势 · INFRAME · 道具 persist+morph+≥1 novel · 拍密度+时长表 · BANNED twin · Mode 两句+知识锚。
3. 故事/hybrid 额外：角色卡（≤3）+ **冲突→翻盘表**（每格=可见画面变化）。
4. 交付：`STYLE-BASE` 挂接或本集 `DISTILL-GAP.md` 顶栏预填 Gate 空位。

### Step 3 · densest ~10s（先证明再投资）
densest **旁必须贴**：
- 字阶表 + 3s motion list
- 故事/hybrid：冲突→翻盘表
- contact sheet **或** ≥6 张 densest 静帧路径（无物证 = Vanity Fail）

渲染带 `?norun`（禁 RAF 与截帧同开）。

### Step 4 · Pre-score Gate G0–G7 + Award /55
权威：`AWARD-SCORECARD.md` §0。

| Gate | 过线 |
|------|------|
| G0 | 九项蒸馏挂接齐 |
| G1 | **crop-bottom mute**：裁底 ~12–15% 静音 10s 仍懂机制 |
| G2 | 字阶 ≥4 级可见 |
| G3 | 无 card-swap；persist+morph / path-walk |
| G4 | ≥1 道具仅凭状态变化能猜理论 |
| G5 | 自己静音连看：不会划走 |
| G6 | densest 物证在 |
| G7 | 故事/hybrid：冲突表+角色可认回；**禁纯卡墙** |

然后打 `L M C N T X H D G K F = ??/55`：
- C/G/T/N/X/D ≥4 必须 **帧路径+动势/字阶/道具** 证据，否则封顶 3
- L/M≤3 → N/X/H/G/K 软顶 4（防丑片灌分）
- **Pass**：Gate 全绿 + ≥44 + N/X/D≥4 + L/M/F≥4 + HUMAN-CHECK 无 No + 无硬失败
- **Near-pass / Fail**：先改最低维，**禁止**宣称获奖级

### Step 5 · HUMAN-CHECK（强制）
`episodes/<slug>/qa/HUMAN-CHECK.md`：

```
1. 我会划走吗？     Yes划走 / No留下
2. 静音能懂机制吗？ Yes / No
3. 有一个新道具吗？ Yes / No
```

故事/hybrid **再加戏感三问**：
```
S1. 谁跟谁较劲？
S2. 10s 内局势变了吗？（可见状态）
S3. 换文案同一道具还能演吗？
```
任一 No / 划走 → **最高 near-pass**，先改片。

### Step 6 · 用户看 densest（品味否决权）
- densest Gate 绿 **或** near-pass 已迭代一轮仍卡美观 → **拷 densest 给用户看**（优先于盲拉 short）。
- 用户说 **不好看 / 差远了 / 停** → **立刻停该题**（沉没、木塔先例）；记梯子债；换题或换 craft，**不**加分钟硬撑。
- 用户说可以 / 往上拉 → 进入 short。

### Step 7 · Short 全片（45s–3min 按拍）
- 钩 ≤3–4s；典型叙事拍 ≤4–6s；机制床可长持但须持续状态变
- **禁时长灌水**（沉没 7:00 拒收）
- 全片再打一行 Score（可略严）+ 更新 HUMAN-CHECK
- 竖版抖音用 + 横版可选

### Step 8 · PC 三件套
根：`D:\Vibe知识大赏-试做\<中文夹>\`

> **硬规则（2026-11-01）：** short 交盘三件套外必须含 **文案.txt + 封面.jpg**，禁再漏。
> **拍板（2026-11-01）：** Gate / 下一题 / 备发 = **Jules Pass 或代选即动**，勿再等 Adelaide 点「发/开」。**仅抖音账号最终点发布**留 Adelaide 本人（制作侧不登号代发）。

- 成片 mp4（silent 主交付）
- 封面
- 文案（标题≤20 可含「Vibe知识大赏」口径见 `DOUYIN-PUBLISH.md`）
- densest / 旧版可进 `_archive_*`

### Step 9 · 上梯子
`PROGRESS-LADDER.md` 追加一行：# · 题 · 理论族 · craft · Award 诚实分 · 升级点/债 · 日期。  
回写选题库该行状态（若维护 JSON/表）。

## 2 · 质量怎么知道够不够

### 2.1 机器/文档门槛（先过）
1. **G0–G7 全 pass**（故事强制 G7）
2. **诚实 Award /55**（有帧证；无 vanity）
3. **HUMAN-CHECK** 通用三问 + 故事戏感三问
4. **INFRAME**：论证拍 ≥70% 图内道具/标注；裁底栏仍懂；**禁图内字+底白同义复读**（六层）
5. **硬失败清零**：频闪字、翻页卡墙、~20s 英雄字 dwell、BANNED twin、编造 %

### 2.2 品味门槛（一票否决）
| 信号 | 动作 |
|------|------|
| 用户「不好看 / 差远了」 | **停题**，记债，不辩数字 |
| 自己 densest 会划走（G5） | 最高 near-pass，改钩/道具/动势 |
| 数字 ≥44 但无密帧 | **Vanity Fail**（旋律教训） |
| stick+双账 HUD / 塑料 3D / 博物馆 GPU | 视为已知失败皮，默认不冲 |

### 2.3 够不够开 short？
| densest 结果 | 建议 |
|--------------|------|
| Pass + 用户 OK | 拉 short |
| Near-pass（美观 L/M/F）+ 用户要看效果 | 可拉 **短** short 审；不冲材质堆分钟 |
| Near-pass + 用户嫌丑 / Gate 红 | **停**，换底座或换题 |
| Fail / Vanity | 禁止 short |

口诀：**densest 不过关 = 还不配花 short 的算力。**

### 3.3 轮换规则
1. **相邻两集 craft 家族不同**（story / darkgold-music / transit / countdown / desktop / chalk / circuit / game-show / iso / printed / memphis …）。

4. 支线 AI/工具约 20–30%，勿连发幻觉/讨好/RAG。

## 4 · 建议节奏（工厂节拍）

### 推荐默认：**1 densest →（用户看）→ 1 short**
适合现在「质量不确定、要一个一个出」：
1. 从 SHOOT 头拣 1 题  
2. 做完 densest + Gate + HUMAN-CHECK（目标 ≤1 个工作节律内可审）  
3. **停下来给你看 densest**  
4. OK → short + PC；Neg → 改一版 densest 或换题  

### 备选试味批：**3 densest → 挑 1 条 short**
当连续不确定「模版好不好看」时：
- 一次排 3 题、**3 个不同 craft 家族**（例：story · transit · chalkboard）
- 只做到 densest Gate，并排给你看  
- 只把味道过关的那条拉成 short  
- 另外两条 near-pass 可归档或改底座，**不**三条一起灌全片  

### 不推荐
- 无 densest 直接 3–7 分钟全片  
- densest Fail 仍「先出完再说」  
- 同周决策偏差或同 craft 连发三集  

### 每集时间盒（经验）
| 阶段 | 占比感 |
|------|--------|
| UPGRADE+蒸馏挂接 | 短；缺九项就停 |
| densest+Gate | **主成本**；质量闸门 |
| short | 仅 densest 过关后 |
| PC+梯子 | 收尾固定 |
