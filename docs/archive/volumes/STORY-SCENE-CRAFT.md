## 0. 一句话

静音主线里，「像电视剧」= **同一批角色在同一场景里把机制演出来**（冲突→动作→翻盘），而不是每 3 秒换一张信息卡。  
图解床（波形 / 双曲线 / 地图进度）仍然有用——但那是**另一条车道**，别把社交/人际选题硬塞成 PPT。

---

## 1. 「像电视剧」像素级长什么样

| 维度 | 故事场景型（要） | 死板模版（禁当主讲） |
|---|---|---|
| **角色** | 全片可认回：同一剪影/袍色/夹克/lone 铜金人；换景不换人设 | 每屏新图标人，无连续性 |
| **场景** | 电梯厢、圆桌、夜行路、雨夜亭——**布景 persist**，灯/墙/门框跟着走 | 纯色底 + 浮动卡片墙 |
| **节拍** | 冲突可见 → 动作（低头刷、撕公文、举盾）→ 关系/局势变 → 翻盘 | 同级卡 swap 文案；清单打勾 |
| **镜头感** | 全景定场 → 中景动作 → 特写道具/表情线；正反打或反应镜 | 整页硬切、无视线引导 |
| **服化道** | 道具讲戏：手机=盾、公文纸屑、倾杯金液、聊天泡错对 | 只有数字/标题漂浮 |
| **字的角色** | 图内气泡/对白/HUD 标签是戏的一部分；底白只偶尔补一句 | 底栏整段解说复读画面 |
| **时间** | 因果链：因为 A 做了 X，所以 B 变了 | 并列「知识点 1/2/3」 |

静音能测的「戏感」三问（HUMAN-CHECK 加戏版）：
1. 遮住底白，**谁在跟谁较劲**？说得出角色关系吗？  
2. 10 秒内有没有一次**可见局势变化**（盾亮、泡变色、纸被撕）？  
3. 换掉文案换个选题，**同一套人物+道具还能不能演**？能 = 故事底座；不能 = 只是换皮 PPT。

## 2. 对照：死板模版长什么样

常见假「知识动画」签名（Award C/G 易虚高）：
- **Card-swap**：每句一整张新卡，布局重置  
- **Checklist 墙**：多行同级条，只改勾选  
- **Floating stats only**：大数字+短句，无行动主体  
- **HUD 说明书**：层名/进度划在讲课，舞台上没人在做事  
- **同义复读**：图内已写「安全行为」，底白再念一遍（六层教训）

这些在 **moyou 波形课**里可以是合法辅件；一旦选题是「人在电梯里假装看手机 / 六层卸防问法」，再用纯卡墙 = 用户说的「死板」。

## 3. 何时选故事场景 vs 图解床（Vibe知识大赏 · silent）

| 选题信号 | 优先车道 | 本地底座锚 |
|---|---|---|
| 人际/话术/卸防/错对问法 | **故事 · 微剧场**（聊天气泡正反打） | `xiaomo-darkgold-disarm`（WrongRightPair ≈ 小剧场对白） |
| 社交焦虑 / 人多 / 安全行为 | **故事 · 群戏+道具盾** | `nexo-crowd-phone`（pill 人群 + PhoneShield） |
| 第一印象 / 晕轮 / 投射 | **故事 · 剪影寓言** | `sanhao-halo-effect`（HaloSilhouette / RelabelPair） |
| 史实辟谣 / 人物命运 | **故事 · 纸偶史剧** | `lailong-xuanzang-passport` / `lailong-zhaoyun-infant` |
| 学习对照 / 双角色寓言 | **轻故事 · 双色角色** | `zhongshan-learn-fast` |
| 音乐预期 / DROP / 脑区曲线 | **图解床**（persist 波形+位点） | `moyou-darkgold-music` |
| 电路/路线图/步骤秩序 | **图解/沙盘** | lemo：`circuit-board` / `transit-map` / `isometric-picture-book` |
| 平台期 / 顿悟 /「努力看不见回报」 | **故事 · 微剧场 + persist 格子** | `moyou-story-percolation` |

**混用规则：** 故事主线里可以塞 1 个示意仪表（紧张表、层进度），但仪表是**戏里的道具**，不是下一张 PPT。图解主线里可以闪一下剪影人，但人不能抢走 persist 床的讲课权。

## 4. 蒸馏清单加项（贴进 DISTILL-MULTIDIM / INFRAME）

做底座或 densest 前多勾这几条：

1. **Narrative mode 锁一句：** `story_scene` / `diagram_bed` / `hybrid` —— 并写「观众跟着谁的欲望受阻」。  
2. **角色卡（故事必填）：** 人数 ≤3；每人 1 视觉签名（色/剪影/道具）；全片可认回。  
3. **冲突→翻盘表：** 钩冲突 · 阻碍动作 · 机制露出 · 翻盘/金句 —— 每格对应 **可见画面变化**（不是只换字）。  
4. **镜头连续：** densest 10s 内至少 1 次景别或视线转场；禁止同布局文案轮换充当「剪辑」。  
5. **道具即机制：** 主隐喻道具必须 morph 状态（手机→盾、错泡→金泡、公文→纸屑）；纯标签贴图 = Fail G。  
6. **反模版门：** 陌生人静帧若第一反应是「又一张知识卡」而非「这段戏在干嘛」→ 打回重蒸（与 D8 twin 并列）。

## 6. 对我们管线的落地建议（先记，不重做）

- **电梯假装看手机 / 六层卸防** 已在故事车道：继续压 **人物动作 + 道具状态**，底白只稀疏辅助（已锁 INFRAME §2b）。  
- **规划谬误双针** 偏图解仪表：保留针/GAP，但若用户要「更像电视剧」，应加 **同一催工角色跨幕**（日历/老板剪影 persist），而不是多加卡片。  
- 新蒸底座时：SILENT compare 表加一列 **story | diagram | hybrid**，避免社交选题误套 moyou 波形语法。
