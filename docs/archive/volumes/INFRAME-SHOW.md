## Craft rules (hard)

### 1. Beat ownership (≥70%)
For every argument beat in the beat sheet, tag carrier:
- **INFRAME** — prop state change, callout, path-walk, meter, wrong/right pair, DROP marker, dual curve, shield morph…
- **PUNCH** — bottom / edge one-liner (optional)
- **ANCHOR** — top-left title / layer HUD (orientation, not full lecture)

**Fail if** INFRAME beats < 70% of argument beats in densest 10s **or** full cut sample reel.

### 2. Bottom strip demoted
- Optional. ≤ **1 short sentence** (prefer ≤14 汉字); never 2-line lecture.
- Never the only place the mechanism is named.
- Xiaomo family: NarrativeLine = **scene hook / punch**, not the wrong↔right lesson (that lives in ChatStack).
- Moyou family: **no** bottom narrative band (footnote only).
- Grain / film noise **never** on text safety bands.

### 2b. 禁同义复读（user lock 2026-10-31 · 六层卸防）
Silent / no-VO 主线：**画面里已经写出的字/层名/道具标，底白字禁止再念一遍同义句。**
- 底条只做「画面没写清」的稀疏辅助（少 · 短 · 偶尔），不是平行字幕轨。
- 人同时看图内字 + 底白复读 → 看不过来 → **硬失败**（见 AWARD **G/T**）。
- 自检：把底条抠掉后，图内字是否已经讲完？若是 → 该拍 **删底条**，勿留回声。

### 3. Mute-test · crop bottom
Acceptance (densest + Gate):
1. Mute audio.
2. Crop / mask bottom **~12–15%** of frame (strip + footnote).
3. Watch 10s densest window.
4. Must still: name the mechanism gesture (**G≥4**), read hook/number/callout (**T** not collapsing to ≤3).

If understanding dies when strip is gone → **T≤3 · G≤2 · near-pass max** (see AWARD-SCORECARD).

### 4. Gadget grammar (steal from densest, invent props)
| Pattern | Evidence | Use when |
|---------|----------|----------|
| Path-walk + site label | moyou DROP / playhead /「走到哪标到哪」 | Music, timeline, process |
| Dual curve / dual clock | moyou expect vs climax; planning dual-axis | Contrast mechanisms |
| WrongRightPair / ChatStack | xiaomo red✕ vs gold✓ | Social / choice lessons |
| Callout leaders on anatomy | moyou brain 尾状核/伏隔核 | Map → label |
| Meter + morphing shield | nexo tension → phone shield | Pressure → coping |
| HUD progress (not lecture) | xiaomo LayerMeter | Chapter orientation |
| StoryBeat / ScenePersist | nexo jacket+shield; xiaomo chat FSM; lailong stick acts | Social / history / anxiety — **play** mechanism |

**Invent** episode-specific gadgets; **keep** family palette + persist/morph discipline.

### 5. Persist + morph (anti flip-book)
Main stage object survives across title/punch changes. Morph state (fill, highlight, open bubble, move playhead). Hard-reset whole layout every beat → C/G hard-fail (翻页).

### 6. Hierarchy (big → small)
1. Hero gadget / diagram  
2. On-canvas callouts & numbers  
3. Top title / layer name  
4. Optional punch line  
5. Dim footnote  

If (4) is larger/louder than (1)(2), redesign.
