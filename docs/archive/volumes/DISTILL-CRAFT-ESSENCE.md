## 1 · 跨片 KEEP（可执行）

从导演 M1–M7 + VISUAL-7 + FX 切型 + 故事床抽出；densest 自检。

1. **先声明册 + 切型**  
   H/V/S/P/E/R + A/B/C（或 S/P/E 物切）。分型差=导演差：C 旅程 ≠ A 换板 ≠ B 稀切论证 ≠ R 高切课堂。

2. **M1 钩可截图**  
   打脸句单独能当封面。禁行程单「一天四站」、纯概念名无冲突、编年旁白开场。

3. **M2 翻盘=可见态差**  
   缺席/反讽/数据对打/物态贯通 ≠ 只换字幕。禁列表打勾当冲突；禁火焰特效冒充 AbsentSignal。

4. **M3 道具=机制（persist 床）**  
   全片同一视觉主语 ≥3 态（地图/炬/金网/点云/棋盘/谱面/手机盾…）。论证靠物理态差，不靠换卡。

5. **M4 先演后命名**  
   机制态早于公式/金句大字。E/R 可早命名，但须打脸或点在动。禁开场公式墙。

6. **M5 主讲权轮换**  
   Text / Gadget / Dual 有交接；禁连续 ≥3 拍字墙；禁底白口播复读当正文。INFRAME 论证拍 ≥70%（底栏最多一句 punch）。

7. **M6 反转三层**  
   惊讶（钩）→ 机制（床态）→ 照进你（提问/当代锚）。禁只有①无③；禁③纯说教无画面回扣。

8. **VISUAL-7 观感必过（按册）**  
   - V1 中区：H 地形床须 full/near-full；V 虚空 sparse **合法但禁抄进 H**  
   - V3 体量：H 建筑大–中；禁火柴人+细线地图  
   - V4 材质：浮雕/纸纹/虚空膜；禁深褐空板冒充浮雕  
   - V5 形体受光（非仅 UI 发光）  
   - V7 转场必须匹配本卡切型

9. **故事床 vs 图解床**  
   人际/命运/卸防 → 同一批角色+场景把机制演出来（冲突→动作→翻盘）。图解床（波形/双曲线）是另一车道——别把社交题硬塞 PPT。混用：仪表只能是戏里道具。

10. **粒子/FX 纪律（摘要）**  
    粒子落在论证剪影/板面/路径内；禁氛围灰压字幕。突破=1f step+短 settle，非秒级 ease。整板换场用 step，勿假 dissolve「顺滑」。

11. **内容跟着画面走 · 要故事 · 禁死模版**（流量硬门 · 2026-11-02 Adelaide）  
    - **一句一态**：每句屏上字必须咬一个可见动作/道具态差；同构图只换字 = Fail。  
    - **题材换语法**：册/切/床随选题变；禁止连拍同一套布局换皮（「一成不变模版」）。  
    - **故事优先**：人际/道歉/归因/期望类 → 故事床（冲突→动作→局势翻盘）；图解/仪表床仅当机制本身是系统态（同步/概率/光谱），且仪表须是戏内道具。  
    - **数据锚**：越学越快(~4k) ≫ 第一印象(267)等——内容跟着画面走、有故事的更吃播放。

12. **多角度 + 画面体量**（Adelaide Fail 道歉 v1）  
    故事床也须 **≥3 论证角度**换景换态，不是一条道歉戏演完就收。  
    中区角色/道具须 **半屏以上体量**；简笔小火柴浮空灰底 = 画面 Fail（「这画面也太…」）。

## 2 · BAN（跨册 twin）

- **未读 CRAFT-ESSENCE + 对应 CARD** 就开 densest  
- **用 R/玉玺 A 切密度做来龙 C 旅程**；用 V 虚空当 H 地形床  
- 行程条 / 路径% / WAVE HUD 当主戏  
- 同布局文案轮换当「剪辑」或「翻盘」  
- 把 MEASURED 表整段粘进 lock（twin）；只报「事件 3 态 / Award 过了」跳过导演门  
- E 预告假装三层齐全；`769971` 热点薄钩当范本  
- **同布局连拍换皮**（一套模版换题）；内容在讲故事、画面仍是仪表说明书  
- **单角度故事线**当 densest；**瘦小中区**无雕塑级体量  
- 同构图换字幕冒充「剪辑」或「内容密度」  
- VISUAL-7 平均数抹平分册；FX 切密度冒充「导演方法」

Fail 锚：苏轼路径条 densest；平安火改成火焰高潮；节奏 53 切抄进烽火。
