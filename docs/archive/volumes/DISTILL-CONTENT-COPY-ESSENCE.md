## 0 · 怎么用（30 秒）

1. 定选题类型 → 按下表开 **一卡**（见 `DISTILL-CONTENT-COPY-CARDS.md`）  
2. 读本文件 §1 KEEP + §2 BAN  
3. 借的是 **职能**，不是某 clip 原句（禁 twin）  
4. 写 CONTENT-BOARDS：≥6 short / ≥5 densest；每板屏上句 + 态差 + 接触  
5. 三结构候选里 **至少一个拒绝抄 Ember 九槽**

| 选题类型 | 开哪张卡 | 典型构念 |
|---|---|---|
| **历史 / 人物戏** | **卡 A** | 制度·身份态差·典籍·时间箱 |
| **心理 / 机制** | **卡 B** | 误读→机制→原典→回钩；构念分账 |
| **方法 / 训练** | **卡 C** | 可演步·接触点；加载轴仅当题材需要 |
| **科学 / 公式 / 概率** | **卡 C** | 先例子后命名；检查单/计数 |
| **情绪短片 / UI** | **卡 B**（短打脸+UI 态） | 2–6 板即可，勿硬拉 16 板 |

| 拿不准 | ESSENCE KEEP + 最近一卡；禁默认 Ember | — |

**一句话路由**：人物制度戏→A；脑子里的错模型→B；怎么办/公式/检查单/体感课→C。

## 1 · 跨片 KEEP（可执行）

从全库 ~26 条独立文案脊抽出；写 boards 时逐条自检。

1. **板靠论证赚席**  
   密度 = 换句 + 道具态差，不靠晃镜。赵云 hard≈2.2/min 仍有 ≈32 论证板；知识诅咒 hard≈0.4/min 有 12 软板。

2. **原典可指认**  
   屏上：作者·书/刊·年，或典籍卷次。例：Newton 1990；Schultz Science 1997；《武经总要》烽式；《唐律疏议》卷二十六。  
   **禁**空「研究表明」。

3. **脚注上屏**  
   「示意」「流行模型非实验」「非定律」「从简」与主句 **同帧**。

4. **DualMark ≤2 / 屏**  
   蓝/青=事实·人名·年·书名；红=冲突/命运词；可删线反讽。文案层控制色词数量。

5. **先演后命名**  
   机制/故事演完，公式名或金句后甩。  
   例职能：敲歌实验→才叫诅咒；猜不到→才出比特；鼓旗层层→才甩「一鼓作气」。

6. **回钩 · 同物新义**  
   开头物件/场景重现，意思变了。军报 / 弹孔翼 / 烽火 / 通关文牒「他没有」/ 刷手机→解出一题。

7. **反换皮**  
   Ember 贡献的是 **职能**（钩悖论·误读·机制·原典·可演步·代价边界·回钩·脚注），**不是**「三步+一天轴+五日反抗」九槽。  
   H 用时间箱+典籍；S 用检查单/计数；E 用一句打脸+UI；R 用体感阶梯——勿跨类型粘骨架。

8. **可演接触**（有「怎么办」时）  
   每步手可碰：写一行、泡冰水、关刺激、Type-C 无反面。无接触 = 纸上步 → Hold。

9. **构念分账**（机制/心理必做）  
   本题材几个构念各是什么、片中怎么诚实说、勿与谁混——先表后板。任务切换例见 Ember 语法 §5（子集参考）。

10. **道具链**  
    ≥3 物；至少一物跨 ≥3 板变态。每板填：屏上句 + 态差 + 接触点。

11. **一题多角度**（2026-11-02 Adelaide · 对标火片）  
    同一构念至少切 **≥3 独立角度**（例：误读为何错 / 对方听到什么 / 机制原典 / 对照正确演法 / 边界何时可解释 / 照进你），每角一板一态差。  
    **禁**只拍一条故事线从头演到尾当全片（单戏≠多角度）。故事是载体，角度是论证刀数。

## 2 · BAN

- **未读 ESSENCE + 对应 CARD** 就写 boards  
- **套 Ember 九槽换皮**（选定理由写「对齐 Ember：钩→…→三步→一天→反抗」而无本题材构念）  
- **只抄 OCR 脊骨 / twin 原句**（蒸馏=借职能完善，不是粘贴英雄句）  
- 空「研究表明」；列表墙（危害1/2/3、步骤口号墙）无道具态差  
- 单钩薄片：只有悖论开场，无误读/机制/原典/回钩阶梯  
- **单故事线冒充全片**：缺 ≥3 角度论证板（Adelaide Fail 道歉 v1）  
- 编造未上屏 VO；跨类型抄骨架（R 切字卡≠H 旅程句；星座词云≠机制原典）  
- 纸上 densify：板数齐但无态差/接触 → Hold  
- 把 Ember 当全库唯一文案语法

Fail 锚：苏轼删档；PC11+ 列表墙；task-switch Ember 换皮版。
