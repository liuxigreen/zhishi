### KEEP
1. **钩**：预测落空 / 人生线迷信 / 身体反直觉 / 误名打脸（「不是太粘」）
2. **切型**：V 默认 **B** 稀切长 hold（信息论 6/300s 级）+ 板内 breakthrough step；P=插画切页；E=情绪切（可极短）

4. **「你」可早现**；三层仍要写（短 E 可压成打脸+UI态+一句收束，诚实标短体）
5. **VISUAL-7（V）**：中区 sparse **合法**；近黑虚空+细/胖金线或点云；自发光+vignette；禁假透视街抄 H

## 卡 C · 方法 / 科学 / 公式 / 节奏
合并：S 模拟棋盘 + R 节奏舞台 + 方法可演步（Ember 画面仅当习惯重训需要）

### KEEP
1. **钩**：物理尴尬一句（朝下/猜不到比分）或「这些点叫拍子」定义引入——物或点先在动
2. **切型**：S=堆积/清空为主（可少量硬切）；**R=切型 A**（切密度=课，hard 可极高）；方法习惯题用 B 稀切+接触态，**勿默认 R**
3. **object-first**：骰/针/面包/Type-C/谱面点列先落地 → 堆积计数或检查单态变 → 再命名公式/BPM
4. **计数/检查单**：0/4→3/4 可见；禁口号墙。Buffon：金针压线 vs 灰未压=读数
5. **VISUAL-7（S）**：棋盘/秤盘占中下 half–full；计数物有质量；顶侧光+接触影  
   **（R）**：舞台舞者层+底栏谱面；球灯光束脉冲（≈1s 级）；**禁把 A 切抄进 H/V**
6. **Ember 方法画面**：仅当习惯重训——可演三接触 + 代价脚注同帧；禁九槽换皮到概率课/节奏课
7. **回钩**：单次仍不可知 / 怎让它没法出错 / 训练非对抗 —— 同物新义

### BAN
- 虚空冒充棋盘；无读数的撒针装饰  
- 人物命运史诗运镜（那是卡 A）  
- R 高切 / 聚光脉冲抄进史地或深空长 hold  
- 开场考试体「什么是切分音」而点列未动

### 借职能 · 例（非 twin）
| 参照 | 借什么职能 |
|---|---|
| Buffon 投针 | 针堆积≈1.7s / 清空≈1s；计数=论证 |
| 墨菲定律 | 物落地尴尬钩 + 检查单/朝向态 |
| 速通节奏 | **A** 切=课；定义拍→谱面演示；聚光跟拍 |
| Ember（仅习惯题） | 误读比价床 + 可演步接触；非默认全库 |

### densest locks 怎么填
1. 册=`S`|`R`|（方法 V）· 切型=S物切 或 **A（仅 R/内容即切）** 或 B  
2. 物/点列首帧是否已在场？命名是否在计数之后？  
3. 若启用一天轴：脚注「非定律」+ 接触点；否则写「故意不用一天轴」  
4. 文件头：`已读 CRAFT-ESSENCE+卡C · 物：针/谱面 · 切：S|A · 借用：堆积计数/…`
