## 卡 A · 历史 / 人物戏
合并：旧 H（赵云·烽火·宵禁鼓·打仗信号·玉玺·玄奘）+ 来龙

### KEEP
1. **打脸钩** = 身份锚 + 反直觉动作（压军报 / 官府抓唐僧 / 玉玺「你」被摔）
2. **时间箱或规程箱**：跨年数字、炬数表、鼓点律文——用规程当论证容器，不是年号墙
3. **先演后命名**：制度/故事演完才甩成语或表句（亲贤臣 / 一鼓作气 / 平安火）
4. **SourceFooter 几乎每屏**：据×× / 场面示意 / 课本册次；禁空「史书记载」
5. **缺席当戏**：删线「不会来」、没有的通关文牒、空画框
6. **回钩同物**：开头物件 vs 结局新义（军报 / 那把烽火 / 文牒他没有 / 若玉玺还在）
7. **一天行程禁流水**：时间箱是论证容器，不是「早中晚打卡」日记体

### BAN
- 开场涨幅 HUD / 列表年号墙当论证  
- twin 抄赵云等钩原句  
- 把 R 高频切字卡当旅程句；无典籍脚注的史空话

### 借职能 · 例（非原文）
| 参照 | 借什么职能 |
|---|---|
| 赵云出师表 | 打脸钩 + 三十六年时间箱 + 缺席戏（黄皓升迁/「不会来」）+ 回钩课本 |
| 唐朝烽火 | 规程问答（无敌人？）+ 炬数数字对照 + 层层「从简」脚注 |
| 玄奘无通关文牒 | 小说对照板 vs 史实「他没有」+ 公文/水袋道具链 |
| 传国玉玺 | 物件第二人称贯穿 + 形制卡 + 失踪回钩 |
| 打仗信号 | 第二人称队列沉浸 → 先演鼓旗 → 再甩成语 |
| 长安宵禁鼓 | 当代街景对照 + 《唐律疏议》原典板 + 小说嵌制度 |

### 写 boards 时怎么用
1. 钩是否「身份×反直觉」可截图？  
2. 箱（时间/规程）是否承载论证，而非流水账？  
3. 命名板是否在演完之后？典籍脚注是否同帧？  
4. 回钩物件是否开场已埋？  
5. 文件头写：`已读 ESSENCE+卡A · 借用：… · 参照：赵云/烽火/…（职能）`

## 卡 B · 心理 / 机制
合并：旧 V 机制脊（信息论·熵增·幸存者·知识诅咒·努力更差·容错·DNA·持续努力·vibe热点·作弊学习等）+ 旧 P（道家·古埃及）+ 旧 E（情绪短片）

### KEEP
1. **日常悖论钩**（可截图）→ **误读/反常识** → **机制** → **原典可指认** → **回钩**
2. **构念分账**：本片构念各是什么、诚实说法、勿与谁混——机制题先表后板
3. 脚注：流行简化 / 示意曲线 / 非实验百分比 → **同帧**
4. 生活误读口头禅可上屏（「显然/简单/你懂我意思吧」）当误读板
5. **分概念板**（P）：一目一义（无为≠躺平；留白=器之用）；经文短引即可
6. **情绪短片**：一句打脸 + UI 态变（对话框/已读/字雨）；**2–6 板够用**，勿硬拉 Ember 16 板
7. 隐喻可演（网球一直发球→停一拍）优于标签墙

### BAN
- 单钩薄片；空「研究表明」；危害列表墙  
- **强制** Ember「三步+一天+五日反抗」——多数机制片不需要习惯轴  
- 星座词云冒充机制原典；概念词云无接触例  
- 把 H 的长史书 Footer 体抄进机制短板

### 借职能 · 例（非原文）
| 参照 | 借什么职能 |
|---|---|
| 知识诅咒 | 双原典卡（Newton1990 + Camerer1989）+ 可演接触（橡胶圈冰水）+ 生活口头禅误读 |
| 幸存者偏差 | 反常识钩 → 「只看见飞回来的」→ 命名偏差 → 教人看缺席 |
| 信息论 | 猜不到才是信息 → 香农1948 → **意义不在公式里** 收束 |
| 道家内卷 | 短钩「别硬来」→ 分概念板（道/无为/不争/留白）→ 回钩像水 |
| 焦虑依恋 | 打脸定义 → 症状 UI → 隐喻可演（停一拍）；短片板数自控 |
| Ember | **仅当**习惯重训：误读比价+Schultz1997+可演步+代价脚注——见卡 C |

### 写 boards 时怎么用
1. 先写构念分账表（≥1 行「勿混」）  
2. 阶梯是否齐：钩→误读→机制→原典→回钩？（短情绪片可压成打脸+UI+一句收束）  
3. 有行动建议？→ 接触点；没有？→ 不要硬塞三步一天轴  
4. 文件头：`已读 ESSENCE+卡B · 构念：… · 故意不用：一天轴/…`

## 卡 C · 方法 / 科学 / 公式
合并：旧 S（Buffon·墨菲）+ 旧 R（速通节奏）+ Ember **方法职能**（非九槽）+ V 中「怎么办」类（作弊学习·持续努力等可演部分）

### KEEP
1. **先例子 / 体感，后命名公式**（先掷骰与比分错觉 → 再棣莫弗；先跟着数拍子 → 再 BPM/切分）
2. **计数或检查单拆开**运气/倒霉叙事；检查单要有态变（0/4→3/4 可见），禁口号墙
3. **方法步 = 可演接触**：远离刺激、写一行 ready-to-resume、Type-C 无反面、晚饭后总结 1 概念
4. **加载三步 / 一天轴 / 五日反抗**：仅当题材是 **习惯重训/多巴胺加载类** 才启用；启用则脚注「非定律」
5. 古典原典短册/实验年可上屏（1733 七页；1949 空军；Schultz 1997）
6. 体感课：**定义→体感隐喻→细分→风格**；一句一义，禁术语 glossary 墙
7. 回钩：单次仍不可知 / 怎让它没法出错 / 你会听 / 训练非对抗

### BAN
- 鸡汤「万事皆有概率」无计数板  
- 人物命运史诗句（那是卡 A）  
- **默认**抄 Ember 九槽到任何方法题  
- 开场考试体「什么是切分音」无先听  
- 把 R 的高切字卡当 H 旅程文案

### 借职能 · 例（非原文）
| 参照 | 借什么职能 |
|---|---|
| 墨菲定律 | 命名钩 → 检查单拆开 → 概率误读板 → Type-C「没法插反」→ 回钩怎让它无法出错 |
| Buffon运气 | 赌徒直觉错 → 「数还没发生的未来」→ 古典短册年 → 回钩下一点仍无人知 |
| Ember渴望学习 | 日常悖论 → 误读比价 → 原典锚 → **可演接触步** → （本片才需要的）排期轴 + 反抗非定律 → 回钩训练非对抗 |
| 速通节奏 | 拍子定义 → 走路/转圈体感 → 重音挪反拍 → swing 拖脚；先听后名 |
| 作弊学习 | 金字塔 + **百分比非实验**脚注 → 卡住=缺口 → 一概念可演收束 |
| 知识诅咒（可演段） | 费曼/霍金接触板——方法接触可借入卡 C，机制阶梯仍属卡 B |

### 写 boards 时怎么用
1. 本题是「解释机制」还是「教人做」？前者偏卡 B；后者留在 C  
2. 列出需要的职能；**显式划掉**不需要的 Ember 槽（一天轴？五日条？）  
3. 每个方法步写接触点；公式板必须有「先例子」前置板  
4. 文件头：`已读 ESSENCE+卡C · 需要职能：… · 不用：一天轴/五日/… · Ember仅作子集`
