## 0. 先归册再测

| 册 | 导演一句话 | 默认切密度（见 FX） | 钩子口味 |
|---|---|---|---|
| **H 史地旅程** | 常识打脸 → 制度/器物 persist 床演示 → **缺席/反讽翻盘** → 出处 →「你」提问 | C soft / 稀切（玉玺可 H-A） | 「你以为…」/ 小说vs史实 / 第二人称物 |
| **V 深空论证** | 文化预测或人生常识 → 长 hold 论证体 → 公式/临界晚亮 →「你」落点 | B 稀切 | 预测落空 / 线断了还会长 / 床前明月光 |
| **S 模拟棋盘** | 物先落地（骰/针/面包）→ 堆积计数 → 规则命名 | 物堆积为主 | 物理尴尬一句 |
| **P 绘本质感** | 满幅神话/绘本冲突开场 → 色带切页讲神话机制 | 插画切页 | 神毁灭人类级 stakes |
| **E 情绪** | 日常微场景 + 误名打脸（不是太粘）→ UI 情绪态 | 情绪切；可极短 | 「嗯」/ 依恋命名 |
| **R 节奏舞台** | 定义拍→谱面/舞台演示；切密=内容本身 | A 高密 | 「这些点叫拍子」 |

跨册 twin 禁止（深空金线 ≠ 史地金路径；节奏舞台切 ≠ 烽火 soft）。

## 1. 七项导演维（每片必填）

### M1 · 钩子怎么立（Hook）

| 测什么 | 怎么测 | 记什么 |
|---|---|---|
| 钩型 | 读 `hook_*` 静帧 + 标题原文 | `你以为` / 第二人称物 / 预测落空 / 物理尴尬 / 误名打脸 / 高 stakes 神话 / 定义引入 |
| 钩时 | hook 帧 t；标题是否已写钩 | ≤4s 入戏？标题是否=开场句 |
| 钩是否可截图 | 一句能否单独当封面文案 | 是/否 + 原文 |
| BAN | 行程单「一天做了四件事」；纯概念名无冲突；只换理论名词的卡墙 | |

### M2 · 冲突→翻盘可见节拍（Conflict → Turn）

| 测什么 | 怎么测 | 记什么 |
|---|---|---|
| 冲突可见 | setup/mid：谁/什么在较劲 | 局势一句话 + 帧 |
| 翻盘可见 | turn / AbsentSignal / breakthrough 窗 | **画面状态差**（黑烽、撕文牒、金网长回、格子贯通）≠只换字幕 |
| 与 FX 对齐 | `full_events` hard_cut / soft / breakthrough / gold_ramp 峰 | 翻盘 t 是否贴峰（例：持续努力 ~170.9s） |
| BAN | 同布局文案轮换当「翻盘」；列表打勾当冲突 | |

### M3 · 戏内 persist 床如何带论证（Prop = Mechanism）

| 测什么 | 怎么测 | 记什么 |
|---|---|---|
| 床是谁 | 全片同一视觉主语 | TopoMap / 炬阵 / 金网 / 点云 / 棋盘 / 谱面 / 手机床… |
| ≥3 态 | hook→mid→turn（或 densest 3 态表） | 态差表 |
| 机制=物理 | 论证是否靠床的物理变化讲清 | 是/弱/否 |
| BAN | 仪表/HUD 说明书无人做事；路径%当主戏（苏轼行程条） | |

### M4 · 信息释放节奏（Reveal）

| 测什么 | 怎么测 | 记什么 |
|---|---|---|
| 先演后命名 | 机制态是否早于概念/公式大字 | 命名首现 t（约） |
| 公式何时出 | 公式/金句相对翻盘 | 翻盘前 / 同步 / 翻盘后 |
| 出处节拍 | SourceFooter / 书卷对读何时进 | H 常中后段 |
| BAN | 开场先甩公式墙再补画面；全程底白复读 | |

### M5 · 字幕/hero 与画面主讲权交接（Handoff）

| 测什么 | 怎么测 | 记什么 |
|---|---|---|
| 主讲权 | 各锚帧：Text-lead / Gadget-lead / Dual | 序列 |
| 字位 | hero 区（上左常见）是否挡主物 | 挡/不挡 |
| 相邻换权 | 是否连续 ≥3 拍纯字墙 | 是=Fail |
| BAN | 底栏口播条当正文；字压满幅主戏 | |

### M6 · 「你」落点 / 反转三层（You + Triple flip）

| 测什么 | 怎么测 | 记什么 |
|---|---|---|
| ① 惊讶 | hook 打脸句 | 原文 |
| ② 机制 | mid/turn 床态 | 一句话 |
| ③ 照进你 | `you_*` / close 提问或当代锚 | 原文；约片长 % |
| 第二人称 | 「你」指观众 / 指物（玉玺） | 类型 |
| BAN | 只有①没有③；③做成说教口号无画面回扣 | |

### M7 · 分型差异（Style-book director delta）

| 测什么 | 怎么测 | 记什么 |
|---|---|---|
| 册声明 | H/V/S/P/E/R（+ H-map/stage/doc/A） | 必填 |
| 导演语法差 | 相对同批其他册：钩型、翻盘物、切密度、字权 | 三句内 |
| BAN | 用 R/玉玺 A 切密度做来龙旅程感；把 V 虚空当 H 地形床讲制度 | |

## 3. Gate（导演 · densest 前）

成片 densest / short 开渲前：

- [ ] 已声明风格册（M7）
- [ ] 钩可截图且非行程单（M1）
- [ ] 冲突→翻盘有**可见**态差（M2）
- [ ] persist 床 ≥3 态且机制=物理（M3）
- [ ] 公式/金句不早于演示（M4）
- [ ] 反转三层写进 VISUAL-EVENT / UPGRADE（M6）
- [ ] 与 VISUAL-7 / 切密度册一致（勿用错册语法）

缺任一项 → Hold；不准只报「事件 3 态 / Award 过了」。
