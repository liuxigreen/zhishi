## 1. 七维定义与测量口径

### V1 · 画面占比（screen share）
| 测什么 | 怎么测 | 记什么 |
|---|---|---|
| 主戏区占画幅 | 密帧上画 bbox：地形床 / 人物 / 字 / 虚空 | 各占宽高 %；hero 字区 top-% |
| 中区是否吃满 | 中 50% 面积里「有物像素」比例 | full / half / sparse |
| BAN | 中区大空 + 细线 HUD 冒充满幅史地 | |

### V2 · 空间纵深（depth）
| 测什么 | 怎么测 | 记什么 |
|---|---|---|
| 层数 | 远景地形 / 中景道具 / 近景人物或字 | 层数 1–4 + 谁在哪层 |
| 纵深手段 | 透视路径、雾、叠化半透明、影 | 有/无 + 帧证 |
| BAN | 全平面贴纸无前后 | |

### V3 · 物体体量（volume / mass）
| 测什么 | 怎么测 | 记什么 |
|---|---|---|
| 主物相对画幅 | 烽台/城楼/案几/人物 bbox 对角线 / 画幅对角 | 大（>35%）/ 中 / 小（<12%） |
| 纸偶 vs 建筑 | 人物高 vs 城池高 | 比值 |
| BAN | 火柴人 + 细线地图冒充来龙体量 | |

### V4 · 材质（material）
| 测什么 | 怎么测 | 记什么 |
|---|---|---|
| 地表/墙/纸 | 局部 ROI 纹理描述 + grain σ | 土褐浮雕 / 羊皮 / 纯平虚空 / 木板 |
| 边缘 | 硬边矢量 vs 软边绘本 | hard / soft |
| BAN | 深褐空板冒充浮雕地形 | |

### V5 · 受光（lighting on forms）
| 测什么 | 怎么测 | 记什么 |
|---|---|---|
| 主光方向 | 亮面在左/右/顶；有无自发光道具 | 方向 + 色温 |
| 明暗差 | 同物亮面/暗面 luma 比 | 比值 |
| 与 D10 关系 | vignette、glow 归 D10；本维强调 **形体受光** | |
| BAN | 只有 UI 发光、物体无受光面 | |

### V6 · 遮挡（occlusion）
| 测什么 | 怎么测 | 记什么 |
|---|---|---|
| 谁挡谁 | 人物/建筑/字/雾的前后 | 序 |
| 半遮 | 雾、叠化、文书压地图 | 有/无 |
| BAN | 所有元素同层并排不挡 | |

### V7 · 镜头运动与转场（camera + transition）
| 测什么 | 怎么测 | 记什么 |
|---|---|---|
| 镜头 | push / pan / path-follow / static hold | 类型 + 时长 |
| 转场 | soft wipe / dissolve / 1f step / morph | 与切密度分型 A/B/C 对齐 |
| 速度与停顿 | 动段 ms；静段占比（约 1/3 可读） | |
| BAN | 史地册用高频 step；深空册用无意义 soft 糊 |
