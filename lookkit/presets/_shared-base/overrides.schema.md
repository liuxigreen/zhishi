# overrides 字段（写在 REF-LOCK / 具名 preset.json）

| 字段 | 含义 | 例 |
|---|---|---|
| `palette` | 色角色表 | ink: xuan+vermilion · noir: navy+sodium |
| `light` | 主光/轮廓/禁自发光范围 | 钠灯单键 |
| `material` | 命名材质 | ink wash / wet asphalt / FR-4 |
| `camera` | 运镜与切型 | continuous path · soft |
| `caption` | 相对 shared 的字号/描边差 | dark-world outline |
| `BAN_extra` | 本风额外禁 | 水墨纸纹混进钠灯 |
| `engine` | 真跑路径或 stub | style-ink-land-v3 |
